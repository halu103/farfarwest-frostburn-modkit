The build tooling downloads pinned release assets from
[UE4SS-RE/RE-UE4SS](https://github.com/UE4SS

West compatibility configuration also originates from that project. RE-UE4SS
is used under its MIT license.

Baseline compatibility commit:
`5b2663e955a2dfa15d7d960415dc737608dc676d`.

## Far Far West

Far Far West and its executable/assets belong to their respective owners. No
game files or cooked game assets are included in this repository. The
compatibility scanner reads a locally installed executable to calculate a hash
and locate byte signatures. Installation changes only the user's local game
directory after creating a recoverable backup.

## Owned mod source

`FFWFrostburn8` and this repository's maintenance scripts are original project
source released under the repository's MIT license. The build has no dependency
